## 查看、启动和停止本次环境

浏览器中已保留登录后的验证页面。在其他浏览器登录时使用本机的[测试站点登录信息](D:/monipan/.docker/docker-verification-20261028-dce4950b/测试站点登录.txt)。此文件只存在本机被 Git 忽略的目录，不把密码复制进项目文档。

三个服务不设置自动重启，按需使用。PowerShell 中可启动本次已构建镜像：

```powershell
$taskVerify = 'D:\monipan\.docker\docker-verification-20261028-dce4950b'
docker compose --env-file "$taskVerify\verify.env" -p monipan-verify-20261028-dce4950b -f "$taskVerify\compose.yaml" up -d --no-build --pull never --wait
```

停止本次验证服务，保留其测试数据和原站点：

```powershell
docker compose --env-file "$taskVerify\verify.env" -p monipan-verify-20261028-dce4950b -f "$taskVerify\compose.yaml" stop
```

以上项目名和目录只对应本轮固化镜像；以后修改源码需重新构建，单纯启动不会带入后续改动。原 `monipan` 项目不使用这些命令。本轮未删除任何已有容器、卷、镜像或用户数据；临时测试容器完成后自动移除，验证站点及其独立数据卷保留。
