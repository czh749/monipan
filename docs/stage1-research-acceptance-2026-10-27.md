开发分支：`codex/stage1-research-20261027`；准备分支及原有提交保留。

## 范围和行为

- 可搜索交易所目录中的沪深主板、创业板、科创板 A 股；2026-10-27 实际同步 **5,223 只**。排除北交所、港美股、ETF、基金、债券和存托凭证。
- 默认 200 只维持原交易规则；每账户最多添加 30 只池外股票。重复添加幂等，默认池自选不占配额，移除只释放自己的关系。
- 新增池外股票仅研究。后端订单预览、提交、待成交撮合均检查限制；没有有效价格时，AI 行情工具返回 `NO_DATA`，不把 0 占位作为证据。
- 股票列表按默认池与本账户自选、正持仓、待成交委托返回；共享采集集合使用默认池、有效用户自选、正持仓和待成交委托。移除关系不删除股票、缓存或历史。
- 目录表独立于报价表。搜索只读本地数据库，不触发外部抓取或 AI。目录保留官方来源、采集时间、板块与上市日期；停复牌等交易状态未核实，显示未知。
- 使用现有单个行情循环处理首次报价：每次最多 20 只，等待期间每 20 秒检查；同一失败代码退避至少 5 分钟，普通行情轮次可提前恢复。历史逐只补齐，财务、公告沿用详情页按需加载。多用户共享同一报价实体。
- 行情准备状态先用 `pending / ready`；K 线、财务和公告沿用现有分项加载、失败与重试界面。本版没有新增持久化任务队列，也不承诺全市场每 5 分钟刷新。

## 本地使用

以下只用于自己的隔离开发库。不要在现有无版本库上直接执行，也不要拿阶段 0 旧发布脚本发布新版本。

```powershell
cd D:\monipan\backend
$env:MONIPAN_DATABASE_URL = 'sqlite:///D:/monipan/.docker/my-stage1-lab.db'
$env:MONIPAN_ENVIRONMENT = 'development'
.venv/Scripts/python.exe -m app.schema upgrade
.venv/Scripts/python.exe -m app.services.security_catalog sync
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 另一终端：cd D:\monipan\frontend; pnpm dev
```

目录同步是显式维护命令，不随启动或搜索运行。七天内更新一次；超过 7 天保留搜索和已有研究，暂停新增池外股票。默认股票不受目录过期影响。同步失败时检查错误类型，保留旧快照后再重试。

后台执行目前要求单个后端进程/worker，与现有部署方式一致。不要使用多个 worker 重复启动行情循环。
